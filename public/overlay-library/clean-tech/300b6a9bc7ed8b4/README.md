# Download vault illustration

One AI-illustrated object generated using existing fal nano-banana access;
fal imageutils/rembg supplied the transparent cutout. Not Rockstar artwork,
gameplay, or a console screenshot. Durable request records are kept in
scripts/news-render/.asset-requests. Estimated provider cost: $0.07 (not invoice).

Original artwork: original.png; validated cutout: overlay.png.
before.png, active.png, result.png are offline deterministic derivatives.
The exact GTA VI text and liquid fill are composited locally, never AI-generated.
The raised illustrated shackle moves down into its socket in the result state.

Rebuild offline:
python3 scripts/news-render/prepare_download_states.py
env -u FAL_KEY python3 scripts/news-render/render_semantic_example.py

Cue timing/placement: scripts/news-render/size212/semantic-cues.json.

original video frame/cut, with the lower object replacing the original bar.
